## 🚀 Key Highlights & Systems

- **GameProject — Souls-like Action RPG Prototype**: Blueprint-driven third-person gameplay in Unreal Engine 5.8, featuring katana combat, stamina, dodge/parry, and character animation in the Snow Shrine test level. In development and being refined through playtesting.
- **Dynamic Weather Shader Lab (MPC Simulation)**: Real-time 3D PBR material simulation running directly on WebGL (Three.js), demonstrating the Material Parameter Collections (MPC) weather system from the `TA_Test` project with zero shader recompilation.
- **Level Utility Tool (EUW_Tool)**: Unreal Engine 5 Editor Utility Widget for in-viewport layout automation, modular level prototyping, and Niagara particle integration on the `IslandLevel` map.
- **Fullstack E-Commerce & AI Chatbot (TeaShop / WebTra)**: MERN stack platform (Node.js, Express, MongoDB Atlas, React, Tailwind CSS) featuring an intelligent NLP AI sales assistant chatbot and VNPAY Sandbox checkout gateway.
- **Niagara GPU Particle Field**: Real-time ambient 3D particle constellation moving dynamically with mouse coordinates and scroll depth.
- **Procedural Web Audio SFX**: Synthesized futuristic UI sound effects using the Web Audio API with zero external audio dependencies.
- **Bilingual Engine (VI / EN)**: Instant language toggle between Vietnamese and English for global studio recruitment.
- **Video Player Modal**: Integrated training showcase from Sparx* - a Virtuos Studio.

## 🌟 Featured Engineering Projects

### 1. [GameProject — Souls-like Action RPG](https://github.com/Dex-NCuong/GameProject)
- **Domain**: Unreal Engine 5.8 • Blueprint • Gameplay • Character Animation
- **Status**: In development / prototype.
- **Highlights**:
  - Katana light/heavy combos, stamina management, dodge i-frames, block/parry, target lock-on, and poise/stagger mechanics.
  - Enhanced Input, Animation Blueprint, and Blend Spaces for locomotion, alongside enemy and mini-boss combat prototypes.
  - Snow Shrine test environment with bonfire/checkpoint, HUD, inventory, and character progression prototypes being refined through playtesting.
- **Portfolio image**: Actual gameplay capture from the project, preserved without editing.

### 2. [Technical Artist Combo (TA_Test)](https://github.com/Dex-NCuong/TA_Test)
- **Domain**: Unreal Engine 5 • C++ 20 • Tech Art • Shaders
- **Highlights**:
  - 5-step C++ Editor Utility Wizard with CDO reflection for automatic enemy Blueprint creation.
  - Zero-recompile dynamic weather master material driven by Material Parameter Collections (MPC).
  - Event-driven zero-tick Ability System using decoupled ActorComponents, Data Assets, and Gameplay Tags.

### 3. [Level Utility Tool (EUW_Tool)](https://github.com/Dex-NCuong/EUW_Tool)
- **Domain**: Unreal Engine 5.4 • Editor Utility Widget • Level Design • VFX
- **Highlights**:
  - Custom Editor Utility Widget (`EUW_LevelTool.uasset`) to streamline asset placement, alignment, and scene management directly in the UE5 Viewport.
  - Interactive testbed environment (`IslandLevel.umap`) combining modular Level Prototyping meshes, Fab marketplace assets, and ThirdPerson character navigation.
  - Integrated Niagara VFX particle systems and clean AAA-standard directory hierarchy (`Island.uproject`).

### 4. [WebTra - E-Commerce & Smart AI Chatbot (TeaShop)](https://github.com/Dex-NCuong/TeaShop)
- **Domain**: Node.js • Express • MongoDB Atlas • React (Vite) • NLP AI • VNPAY
- **Highlights**:
  - Robust backend built with Node.js and Express.js, MongoDB Atlas (Mongoose ODM), and JWT authentication.
  - Intelligent NLP AI Sales Chatbot: Keyword & rule-based natural language processing for tea discovery, budget filtering, weight selection, and direct cart additions.
  - Online payment processing integrated with VNPAY Sandbox (HMAC-SHA512 checksum).
  - Modern frontend built with React.js (Vite), Tailwind CSS, Lucide Icons, and Framer Motion.

### 5. [Sparx* - a Virtuos Studio Internship & Game Jam](https://www.youtube.com/watch?v=7S_7sxQaQYA)
- **Domain**: AAA Game Pipeline • UE5 • Lumen • MetaHuman • PCG • Sequencer
- **Highlights**:
  - 3-month intensive studio training on UE5 lighting (Lumen), materials, cinematic Sequencer, and Perforce (P4V).
  - Game Jam Champion with 1-week rapid prototype ("In Turn" & "Underdog"), leading Blueprint logic, PCG environment, and animation blend spaces.

## ⚡ Quick Start (Local Run)

You can run the portfolio locally with Node.js:

```bash

```

Then open your browser and navigate to:
`http://localhost:3000`

Alternatively, open `index.html` directly in any modern web browser.
